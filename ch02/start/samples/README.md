# 第 2 章教学语料

本目录是第 2–6 章使用的英中教学语料。全部句子由课程作者为本书自写，随仓库文字采用 [CC BY 4.0](../../../docs/content-license.md)；不包含 TinyStories 或其他外部数据集的原文。句子故意保持简单，用来观察 BPE 的合并、压缩率和 OOV，不代表真实语言分布。

## 文件

|文件|行数|字符数（不含换行）|用途|
|---|---:|---:|---|
|`english.txt`|200|9,858|英文训练语料|
|`chinese.txt`|200|2,851|中文训练语料|
|`heldout_english.txt`|2|—|2.5 的英文留出句，不参与训练|
|`heldout_chinese.txt`|2|—|2.5 的中文留出句，不参与训练|

合计 400 行、12,709 个字符；出现 143 个不同的 Unicode 码点。固定示例 `the cat sat on the mat` 和 `小猫坐在垫子上` 各整行出现 3 次。

## 格式与边界

- 一行一句，UTF-8、LF 换行，无空行。
- 语料不包含 `<unk>`、`<bos>`、`<eos>` 的拼写，也不包含 NUL。
- 留出句不参与词表训练。中文留出句里有一个训练语料没有的生僻字 `鑫`，用于 2.5 的 OOV 演示。
- 目标词表 512：3 个特殊 token + 143 个初始码点 + 366 次合并 = 512。

## 复现

语料是固定文件，随仓库提交；第 2.3 节的 `BPETokenizer.train` 读取 `english.txt` 和 `chinese.txt` 训练词表。第 2–6 章不会改动这些文件；第 7 章才换成 TinyStories 中英真实语料。

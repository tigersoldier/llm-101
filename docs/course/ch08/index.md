## 本章目标

- 从第 1 章的 5,824 参数放大到 5,289,472 参数，并逐项解释参数来源。
- 选择 `d_model=256`、4 层、4 头、`d_ff=1024`、上下文 128，并说明取舍。
- 估算每 token FLOPs、激活内存、批次大小和上下文成本。
- 把 `Linear` 初始化从 0.02 换成 `sqrt(2/(in_features+out_features))`，说明放大后为什么换。
- 给 `GPTConfig` 加校验，跑一次最终配置的前向/反向 smoke test。
- 用 tiny config 做全参数有限差分，用最终配置做抽样坐标检查。

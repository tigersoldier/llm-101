# 第 11 章 实验、评估与发布

> 状态：大纲（待写）。本章小节页面随写作上线。

## 本章目标

- 设计同一训练轨迹的 1/3/5 小时对照，固定 seed、验证窗口和记录字段。
- 用固定验证窗口报告混合、英文、中文 perplexity，并解释 PPL 的局限。
- 用固定提示词和固定采样设置检查生成质量，区分“可读续写”和“统计能力”。
- 记录多 seed/采样方差、记忆与污染风险，以及模型不是什么。
- 完成许可复核、代码/权重发布边界和 `final/` 快照。
- 给出后续方向：KV cache、top-p/beam、RoPE/GQA/MoE、指令微调/RLHF、量化和 serving。

## 前置与交接

- 前置：第 10 章；需要可复现的训练 artifact 和样例。
- 交接：`ch11/end` 即 `final/`；全书主线在这里收束。
- 数据/权重：原始语料和 checkpoint 不进入 Git；权重发布以许可复核为前提。

## 本章验收

- `cd ch11/end && uv run pytest -q` 全绿。
- 1/3/5 小时结果可用同一批固定验证窗口重算；分语言 PPL 和样例齐全。
- `final/` 可独立 `uv sync` 与 `pytest`；`final/` 与 `ch11/end` 一致。
- 许可、权重发布边界和“不是什么模型”写清楚。
- 给出可执行的后续方向，不把未实现的功能写成已完成。

## 本章不做什么

- 不做指令微调/RLHF、分布式训练、GPU 优化。
- 不发布未复核许可的权重或原始语料。
- 不把 PPL 或几段样例包装成统计显著的能力评测。

# 1.9 验收、小结与交接

这一节不再增加新零件，也不改变模型的计算。它把整章用同一个例子再走一遍，说明随机权重下哪些量可信，跑完验收，然后把第 1 章的边界和第 2 章的入口写清楚。

## 全章回顾：一条固定的管线

还是用 `the cat sat`。字符级 tokenizer 给它加上 `<bos>`/`<eos>`，得到 13 个编号；编号先查嵌入表、加上位置向量，再进入两个 block（每个 block 依次做 LayerNorm、注意力、残差、LayerNorm、MLP、残差），最后做最终 LayerNorm，再和词嵌入的转置相乘，得到每个位置上的 68 个 logits。最后一个位置的 68 个分数里，编号 3 最大，所以答案是字符 `'d'`。

|小节|这一节新增的零件|形状|关键参数|
|---|---|---|---|
|1.2 tokenizer|文字变成 13 个编号|文本 → `[13]`|无|
|1.3 嵌入|每个编号查一行 16 维向量|`[13]` → `[13,16]`|1,088|
|1.4 位置|给每个位置加上位置向量|`[13,16]` → `[13,16]`|256|
|1.5 LayerNorm 与 GELU|LayerNorm 调匀、GELU 筛选|`[13,16]` → `[13,16]`|LayerNorm 32；GELU 0|
|1.6 注意力|每个位置读取它自己和前面的位置，做加权平均|`[13,16]` → `[13,16]`|1,088|
|1.7 block|Pre-LN：LayerNorm → 注意力 → 残差；LayerNorm → MLP → 残差|`[13,16]` → `[13,16]`|2,224（每个 block）|
|1.8 输出|最终 LayerNorm，再和词嵌入转置相乘|`[13,16]` → `[13,68]`|LayerNorm 32；输出 0（共享嵌入）|

这张表按小节列出新增的零件，不是最终模型的运行顺序；1.7 把 1.5 的 LayerNorm/GELU 和 1.6 的注意力装进一个 block，1.8 再把两个 block 叠进整模型。表里 1.5 和 1.6 行是零件，参数已经包含在 1.7 的 block 里，不能和 block 行相加。参数按最终模型只数一次：两个 block 合起来是 4,448 个参数（每个 2,224）；再加上 token 嵌入 1,088、位置嵌入 256 和最终 LayerNorm 32，全模型共 5,824 个参数。1.8 的图 1.8-1 是整条管线的完整样例，图 1.8-2 是同一件事的架构视图；本节不新增图，只引用这两张图。

1.1 的占位管线只负责逐节演示，最终模型不调用它；每一步的细节分别在第 1.2–1.8 节。这里只需要记住三个量：13 个位置、每个位置 16 维、最后每个位置 68 个候选。每个 block 的输入和输出都是形状为 `[13,16]` 的张量；最终 LayerNorm 之后，输出层把整条序列变成形状为 `[13,68]` 的 logits。

## 验收：把结构确认一遍

先跑根目录的文档与测试检查：

```text
$ uv run pytest -q
47 passed
```

再跑第 1 章的代码测试：

```text
$ cd ch01/end
$ uv run pytest -q
39 passed
```

39 个测试里有几类关键检查：

- `test_forward_shapes`：形状为 `[2,3]` 的编号得到形状为 `[2,3,68]` 的 logits。
- `test_attention_shapes_and_row_sums`：注意力输出形状为 `[5,16]`，每个头的权重矩阵形状为 `[5,5]`，每行权重和为 1。
- `test_causal_mask_hides_future`：改最后一个位置的输入向量，前面位置的输出不变。
- `test_context_limit`：长度为 17 的输入（超过 16 个位置）会被拒绝。
- `test_block_parameter_count`：一个 block 有 2,224 个参数。
- `test_parameter_count`：`parameters()` 返回 36 个张量，共 5,824 个数字。
- `test_last_position_logits_and_argmax`：最后一个位置是 68 个分数，argmax 落在词表内。
- `test_stage_seven_returns_full_model_logits`：stage 7 的分数等于整模型最后一个位置的输出。

最后用第 1 章的占位管线跑一次完整前向：

```text
$ uv run python scripts/show_placeholder.py --stage 7 "the cat sat"
stage 7 | text: the cat sat
ids (13)        [66, 19, 7, 4, 52, 2, 0, 19, 52, 18, 0, 19, 67]
scores          68 | max 0.205 at 3
answer          3
character       'd'
```

`max 0.205 at 3` 里的 3 是词表编号；`character 'd'` 只是把这个编号查回字符。这里的数字来自随机初始化，不是训练后的结果。

## 随机权重：结构是真的，答案不是

模型里的 5,824 个数字由固定 seed 的随机初始化产生，没有经过任何训练。因此：

- 形状、参数量、因果掩码和注意力权重的行和都可以逐项核对；
- logits 的数值没有语义，argmax 得到的 `'d'` 也没有语义；
- 换一个 seed，答案可能改变；例如把同一个 `TinyGPT` 配置的 seed 从 3 换成 0，同一个 `the cat sat` 的 argmax 从 3 变成 67，但管线、形状和参数量的检查仍然成立。

本章的目标不是“让模型说话”，而是让读者能指着任意一个数字说清楚它是哪一步、用哪个形状算出来的。能做到这一点，随机权重就完成了它的任务。

## 本章不做什么

本章只做前向，不训练、不计算梯度，也不读真实语料。tokenizer 是字符级的，不做 BPE；模型只有 2 层、16 维，不放大到第 8 章的尺寸；不做 KV cache、采样循环或网页服务器。原理已经通过 SVG 图、命令行输出和测试展示清楚，不再额外实现一套逐层查看的服务。旧服务器计划的 stage 8、trace 和 `demo` 可选依赖已经删除；本节也不再增加 stage 或 trace。

## 交接：第 2 章

第 1 章的公开接口是后续章节的基线；后续章节对这些接口的修改只有下面列出的这些：

- 第 2 章替换 `CharacterTokenizer`：字符级词表换成 BPE，`encode`、`decode`、`vocab_size`、`bos_id`、`eos_id` 五个接口保持不变，模型侧只更新 `GPTConfig.vocab_size`；另外用第 1 章的 `GPTConfig`、固定 seed 和手写编号做 logits 回归，确认模型代码没有变。
- 第 3 章给 `Linear`、`Embedding`、`LayerNorm`、`GELU` 加 `backward`，并加入稳定的 softmax 交叉熵；`GELU` 从 tanh 近似换成精确 `erf` 形式，其余前向数值不变。它还把 `parameters()` 改为返回 `Parameter` 元组，保留 `numel()`，第 1 章的 5,824 参数测试仍然通过。
- 第 4 章再给注意力、block 和整模型加 `backward`。
- 第 5 章加入优化器，不改变模型尺寸；第 8 章才把 `d_model`、层数、头数、`d_ff` 和上下文放大到最终尺寸，并更新 `Linear` 初始化。

`ch01/end/` 是第 2 章 `ch02/start/` 的来源；本章冻结后，下一章只在这份完成态上继续修改。

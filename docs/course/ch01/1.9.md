# 1.9 验收、小结与交接

这一节不再增加新零件，也不改变模型的计算。它只做三件事：把整章用同一个例子再走一遍，跑完验收，然后把第 1 章的边界和第 2 章的入口写清楚。

## 全章回顾：一条固定的管线

还是用 `the cat sat`。它先被字符级 tokenizer 加上 `BOS`/`EOS`，变成 13 个编号；编号经过嵌入、位置、注意力、block，最后得到每个位置上的 68 个 logits。最后一行的 68 个分数里，编号 3 最大，所以答案是字符 `'d'`。

|阶段|这一阶段做什么|形状|关键参数|
|---|---|---|---|
|1.2 tokenizer|文字变成 13 个编号|文本 → `[13]`|无|
|1.3 嵌入|每个编号查一行 16 维向量|`[13]` → `[13,16]`|1,088|
|1.4 位置|给每个位置加上位置向量|`[13,16]` → `[13,16]`|256|
|1.5 零件|LayerNorm 调匀、GELU 筛选|`[13,16]` → `[13,16]`|LayerNorm 32|
|1.6 注意力|每个位置对它前面的位置做加权平均|`[13,16]` → `[13,16]`|1,088|
|1.7 block|注意力子层 + MLP 子层，各带残差|`[13,16]` → `[13,16]`|2,224|
|1.8 输出|最终 LayerNorm，再和词嵌入转置相乘|`[13,16]` → `[13,68]`|LayerNorm 32；输出 0（共享嵌入）|

把 1.7 的两个 block 也算进去，全模型是 5,824 个参数：token 嵌入 1,088、位置嵌入 256、两个 block 4,448、最终 LayerNorm 32。1.8 的图 1.8-1 是这一条管线的完整样例，图 1.8-2 是同一件事的架构视图；这一节不重复画新的计算图。

每一步的细节分别在第 1.2–1.8 节；这里只需要记住三个量：13 个位置、每个位置 16 维、最后每个位置 68 个候选。形状为 `[13,16]` 的张量一直没有变，直到输出层把它变成形状为 `[13,68]` 的 logits。

## 验收：把结构确认一遍

先跑根目录的文档与测试检查：

```text
$ .venv/bin/python -m pytest -q
47 passed
```

再跑第 1 章的代码测试：

```text
$ cd ch01/end
$ uv run pytest -q
39 passed
```

39 个测试里有几类关键检查：

- `test_forward_shapes`：形状为 `[2,3]` 的编号得到形状为 `[2,3,68]` 的 logits。
- `test_causal_mask_hides_future`：改后面的 token 不会改前面位置的注意力输出。
- `test_context_limit`：超过 16 个位置会被拒绝。
- `test_parameter_count`：`parameters()` 一共返回 5,824 个数字。
- `test_last_position_logits_and_argmax`：最后一个位置的 68 个分数取 argmax，得到词表内的编号。

最后用第 1 章的占位管线跑一次完整前向：

```text
$ uv run python scripts/show_placeholder.py --stage 7 "the cat sat"
stage 7 | text: the cat sat
ids (13)        [66, 19, 7, 4, 52, 2, 0, 19, 52, 18, 0, 19, 67]
scores          68 | max 0.205 at 3
answer          3
character       'd'
```

`max 0.205 at 3` 里的 3 是词表编号；`character 'd'` 只是把这个编号查回字符。这里的数字来自随机初始化，不是训练后的结果。

## 随机权重：结构是真的，答案不是

模型里的 5,824 个数字由固定 seed 的随机初始化产生，没有经过任何训练。因此：

- 形状、参数量、因果掩码和注意力权重都是真的，可以逐项核对；
- logits 的数值没有语义，argmax 得到的 `'d'` 也没有语义；
- 换一个 seed，答案会变，但管线、形状和参数量的检查仍然成立。

本章的目标不是“让模型说话”，而是让读者能指着任意一个数字说清楚它是哪一步、用哪个形状算出来的。能做到这一点，随机权重就完成了它的任务。

## 本章不做什么

本章只做前向，不训练、不计算梯度，也不读真实语料。tokenizer 是字符级的，不做 BPE；模型只有 2 层、16 维，不放大到第 5 章的尺寸；不做 KV cache、采样循环或网页服务器。原理已经通过 SVG 图、命令行输出和测试展示清楚，不再额外实现一套逐层查看的服务。

## 交接：第 2 章

第 1 章的模块接口已经固定，后续章节在这批接口上增量修改：

- 第 2 章替换 `CharacterTokenizer`：字符级词表换成 BPE，`encode`/`decode`/`vocab_size` 等接口保持不变；用固定权重和手写编号做等价性测试。
- 第 3 章给 `Linear`、`LayerNorm`、注意力和模型加 `backward`，并加入 softmax 交叉熵；前向行为不变。
- 第 5 章才把 `d_model`、层数、头数和上下文放大到最终尺寸。

`ch01/end/` 是第 2 章 `ch02/start/` 的来源；本章冻结后，下一章只在这份完成态上增加内容。

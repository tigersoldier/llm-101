# 第 1 章 看得见的 transformer

第 1 章把一个完整但很小的模型一次搭起来：给它一小段文字，它算出“下一个字最可能是谁”。先把整体跑通，1.7 讲 block，1.8 再把它装成完整模型。

这一章不让模型从数据里学东西。它内部的数字都是随机开的头，所以算出来的答案没有意义；有意义的是过程——文字先被换成编号，编号被换成一串串数字，这些数字再经过几道加工，最后变成一组分数。

这样安排不是为了省事，而是为了让过程看得见：每一步吃进什么、吐出什么，都在 SVG 图、命令行输出和测试里写清楚，数字小到可以手算核对。后面几章在这个模型上逐项加细节：第 2 章换一种更高效的切分方式，第 3 章讲模型怎样从数据里调整自己，第 5 章把它放大到最终尺寸。

## 本章验收

- `cd ch01/end && uv run pytest -q` 全部通过。
- `uv run python scripts/show_placeholder.py --stage 7 "the cat sat"` 能复现 `max 0.205 at 3`、`answer 3`、`'d'`。
- 改动后面的字，不会改变前面已经算出的结果。

## 本章不做什么

- 不让模型从数据里学东西（第 3 章起才讲），也不读真实文本数据；模型里的数字是随机开的头，输出没有意义。
- 不换更高效的切分方式（第 2 章），不放大模型（第 5 章），也不为速度做优化（后续章节）。
- 不做 web server、前端页面或逐层 trace；原理用 SVG 图、命令行输出和现有测试展示。

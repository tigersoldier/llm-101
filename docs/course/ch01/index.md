# 第 1 章 看得见的 transformer

第 1 章把一个完整但很小的模型一次搭起来。这类模型叫 transformer；1.7 会讲它由哪些零件组成、为什么这样排，这里先把它当成一个待拆开的整体。

它的任务只有一件：输入一小段文字，输出“下一个字符最可能是谁”。本章只做这一遍从输入到输出的计算，不让模型从数据里学习——模型里的数字都是随机开的头，所以答案没有意义。要看的是过程：文字怎样变成编号，编号怎样变成一串串数字，这些数字又经过了哪几道加工。

这样安排不是为了省事，而是为了让过程可见：每一级的输入输出都能在浏览器里逐格查看，数字小到可以手算核对。后续章节在这套代码上逐项加细节：第 2 章换一种更高效的切分方式，第 3 章讲模型怎样从数据里调整自己，第 5 章把模型放大到最终尺寸。

## 本章验收

- `cd ch01/end && uv run pytest -q` 全部通过，其中包括“分成一层一层算”与“一次算完”结果一致的检查。
- `uv run python scripts/serve_demo.py` 启动后，浏览器里能输入文字，并一层一层看到数字。
- 改动后面的字，不会改变前面已经算出的结果。

## 本章不做什么

- 不让模型从数据里学习（第 3 章起才讲），不训练，也不读真实文本数据；模型里的数字是随机开的头，输出没有意义。
- 不换更高效的切分方式（第 2 章），不放大模型（第 5 章），也不做生成加速（后续章节）。
- 前端不引入构建工具和第三方库，保持可直接阅读。

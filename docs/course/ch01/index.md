# 第 1 章 看得见的 transformer

第 1 章把完整但很小的 decoder-only transformer 一次搭起来：文本进去，每个位置的词表分布出来。本章只实现前向，不做梯度、不训练、不接真实语料，权重由固定 seed 随机初始化。

这样安排不是为了省事，而是为了让结构可见：每一层的输入输出都能在浏览器里逐格查看，参数量小到可以手算核对。后续章节在这批模块上逐项加细节——第 2 章换 tokenizer，第 3 章加反向传播，第 5 章放大到最终维度。

## 本章验收

- `cd ch01/end && uv run pytest -q` 全绿，其中包括"接口链拼出的 logits 与 `TinyGPT.forward` 一致"的等价性测试。
- `uv run python scripts/serve_demo.py` 启动后，浏览器里能输入文本并逐层查看张量。
- 改动后段 token 不会改变前段的注意力输出。

## 本章不做什么

- 不实现反向传播、不训练、不读真实语料；权重是固定 seed 的随机初始化，输出是噪声。
- 不做 BPE（第 2 章）、不放大维度（第 5 章）、不做 KV cache。
- 前端不引入构建工具和第三方库，保持可直接阅读。

# 第 1 章 看得见的 transformer

> 状态：已完成。小节 1.1–1.9 已上线；代码在 `ch01/end/`。

第 1 章把一个完整但很小的模型一次搭起来：给它一小段文字，它算出“下一个字最可能是谁”。先把整体跑通，1.7 讲 block，1.8 再把它装成完整模型。

这一章不让模型从数据里学东西。它内部的数字都是随机开的头，所以算出来的答案没有意义；有意义的是过程——文字先被换成编号，编号被换成一串串数字，这些数字再经过几道加工，最后变成一组分数。

这样安排不是为了省事，而是为了让过程看得见：每一步吃进什么、吐出什么，都在 SVG 图、命令行输出和测试里写清楚，数字小到可以手算核对。后面几章在这个模型上逐项加细节：第 2 章换一种更高效的切分方式；第 3–4 章讲反向传播；第 5–6 章优化器和训练循环；第 7–8 章接真实语料并放大；第 9–11 章生成、限时训练和评估。

## 本章目标

- 跑通文本 → 编号 → 向量 → block → logits 的完整前向。
- 解释每个组件的输入、输出、形状和参数，并给出可手算的例子。
- 用固定示例、SVG 图和命令行输出展示数据流。
- 用测试固定输出形状、因果掩码、上下文上限和参数量。

## 前置与交接

- 前置：基本 Python 和 PyTorch 张量操作；无前章。
- 数据：内置 `ch01/end/samples/stories.txt` 的 6 行示例；不读真实语料。
- 交接：`ch01/end` 是第 2 章起点；tokenizer 的五个成员和 `TinyGPT.forward` 是后续章节的基线。

## 本章不做什么

- 不让模型从数据里学东西，也不读真实文本数据；模型里的数字是随机开的头，输出没有意义。
- 不做反向传播（第 3–4 章）、优化器（第 5 章）、训练循环（第 6 章）。
- 不换更高效的切分方式（第 2 章），不放大模型（第 8 章），不做 KV cache（后续扩展）。
- 不做 web server、前端页面或逐层 trace；原理用 SVG 图、命令行输出和现有测试展示。

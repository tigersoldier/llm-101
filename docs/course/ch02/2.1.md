# 2.1 起点与本章交付物

第 1 章用字符级 tokenizer 把文字变成编号：一个字符一个编号，`the cat sat` 加上 `<bos>`/`<eos>` 是 13 个编号，已经占了上下文 16 个位置中的 13 个。本章的英文样例在它后面加一句 `on the mat`，长度立刻超过上限；中文样例则暴露另一个问题：第 1 章的字符表里根本没有中文。

这一节先不换切分方式。我们跑一遍第 1 章的字符基线，看清这两个问题，再用一张手写的片段合并表演示“把常见片段当作一个 token”的方向。真正的合并规则到 2.2 才由语料统计决定。

## 固定示例

本章从头到尾使用同一对输入：

|样例|字符数|加 `<bos>`/`<eos>` 后的编号数|第 1 章的结果|
|---|---:|---:|---|
|英文 `the cat sat on the mat`|22|24|超过上下文 16|
|中文 `小猫坐在垫子上`|7|9|7 个内容编号全是 `<unk>`|

英文样例是第 1 章 `the cat sat` 的延长，前三个词不变；中文样例的意思对应“猫坐在垫子上”。两条样例一起用，是因为它们暴露的问题不同：英文的问题是序列太长，中文的问题是字符表没有覆盖。

第 1 章的字符表有 68 个符号，其中 65 个是英文字母、空格、换行和常用标点，另外 3 个是 `<unk>`、`<bos>`、`<eos>`。英文样例的每个字符都能在表里找到编号，例如 `t` 是 19、`h` 是 7、`e` 是 4、空格是 52；22 个字符加上两个特殊 token，得到 24 个编号。中文样例的 7 个字一个也不在表里，全部落到 `<unk>`，所以编号里看不出原文。

### `character_encode`

`character_encode` 用第 1 章的 68 个符号把文本变成一个编号列表，按字符逐个查表；查不到的字符映射成 `<unk>`。它和 `CharacterTokenizer.encode` 的行为一致，只是把第 1 章的字符表冻结在这个演示文件里，不依赖第 1 章的快照。

输入是 `str`；输出是 `list[int]`，长度等于字符数，再加上可选的 `<bos>`/`<eos>`。

```text

[66, 0, 1, 67]
>>> character_encode("小猫", add_bos=True, add_eos=True)
[66, 65, 65, 67]
```

### `hand_merge`

`hand_merge` 是本节的手写占位：把文本拆成单个字符，再按固定顺序执行五条片段合并。它不是 2.2 的算法，也不会根据语料频率改变顺序；它只负责让英文样例变短，便于对比。

五条合并是：

|合并|作用的片段|合并后|
|---|---|---|
|`a` + `t` → `at`|`cat`、`sat`、`mat`|`c` + `at`、`s` + `at`、`m` + `at`|
|`s` + `at` → `sat`|`sat`|`sat`|
|`m` + `at` → `mat`|`mat`|`mat`|
|`t` + `h` → `th`|两处 `the`|`th` + `e`|
|`th` + `e` → `the`|两处 `the`|`the`|

输入是 `str`；输出是 `list[str]`，每个元素是一个字符或一个合并后的片段。

```text
>>> hand_merge("the cat sat on the mat")
['the', ' ', 'c', 'at', ' ', 'sat', ' ', 'o', 'n', ' ', 'the', ' ', 'mat']
```

```python
def hand_merge(text: str) -> list[str]:
    # 按固定顺序执行五条合并；返回符号列表
    ...
```

`cat` 最后是 `c` + `at`，`on` 仍然是 `o` + `n`：手写合并是部分的、任意的，故意不覆盖所有词。`at` 同时出现在 `cat`、`sat`、`mat` 里，是本节最值得注意的现象——同样的片段出现在多个词里，才有资格被合成一个 token。2.2 会让算法自己统计这件事。

### `context_error`

`context_error` 用第 1 章的 `GPTConfig` 和 `TinyGPT` 建一个 68 词表的小模型，把文本的编号送进去；如果超过上下文 16，就把 `ValueError` 的消息返回，否则返回 `None`。它只做构造和捕获，不训练，也不改变模型。

输入是 `str`；输出是 `str | None`。

```text
>>> context_error("the cat sat on the mat")
```

## 参考实现

下面是 `src/llm101/baseline.py` 的参考实现。常量、冻结字符表和五个函数都在这里；`scripts/show_tokenizer.py` 只负责读取并排版结果。

```python
from __future__ import annotations

from collections.abc import Sequence
from dataclasses import dataclass

_CHARACTERS = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ .,!?;:'\"-()\n"
SPECIAL_TOKENS = ("<unk>", "<bos>", "<eos>")
CHARACTER_VOCABULARY = (*_CHARACTERS, *SPECIAL_TOKENS)

_TOKEN_TO_ID = {token: index for index, token in enumerate(CHARACTER_VOCABULARY)}
UNK_ID = _TOKEN_TO_ID["<unk>"]
BOS_ID = _TOKEN_TO_ID["<bos>"]
EOS_ID = _TOKEN_TO_ID["<eos>"]

CONTEXT_LIMIT = 16
ENGLISH_SAMPLE = "the cat sat on the mat"
CHINESE_SAMPLE = "小猫坐在垫子上"

_HAND_MERGES: tuple[tuple[str, str], ...] = (
    ("a", "t"),
    ("s", "at"),
    ("m", "at"),
    ("t", "h"),
    ("th", "e"),
)


def character_encode(
    text: str,
    *,
    add_bos: bool = False,
    add_eos: bool = False,
) -> list[int]:
    ids = [_TOKEN_TO_ID.get(character, UNK_ID) for character in text]
    if add_bos:
        ids.insert(0, BOS_ID)
    if add_eos:
        ids.append(EOS_ID)
    return ids


def character_decode(
    ids: Sequence[int],
    *,
    skip_special_tokens: bool = True,
) -> str:
    pieces: list[str] = []
    for token_id in ids:
        if token_id < 0 or token_id >= len(CHARACTER_VOCABULARY):
            raise ValueError(f"token id out of range: {token_id}")
        token = CHARACTER_VOCABULARY[token_id]
        if skip_special_tokens and token in SPECIAL_TOKENS:
            continue
        pieces.append(token)
    return "".join(pieces)


def _merge_symbols(symbols: Sequence[str], pair: tuple[str, str]) -> list[str]:
    left, right = pair
    merged: list[str] = []
    index = 0
    while index < len(symbols):
        if (
            index + 1 < len(symbols)
            and symbols[index] == left
            and symbols[index + 1] == right
        ):
            merged.append(left + right)
            index += 2
        else:
            merged.append(symbols[index])
            index += 1
    return merged


def hand_merge(text: str) -> list[str]:
    symbols = list(text)
    for pair in _HAND_MERGES:
        symbols = _merge_symbols(symbols, pair)
    return symbols


@dataclass(frozen=True)
class BaselineReport:
    text: str
    ids: list[int]
    unknown_count: int
    decoded: str
    hand_symbols: list[str]

    @property
    def char_count(self) -> int:
        return len(self.text)

    @property
    def token_count(self) -> int:
        return len(self.ids)

    @property
    def over_context(self) -> bool:
        return self.token_count > CONTEXT_LIMIT

    @property
    def hand_token_count(self) -> int:
        return len(self.hand_symbols) + 2


def build_report(text: str) -> BaselineReport:
    ids = character_encode(text, add_bos=True, add_eos=True)
    return BaselineReport(
        text=text,
        ids=ids,
        unknown_count=sum(1 for token_id in ids if token_id == UNK_ID),
        decoded=character_decode(ids),
        hand_symbols=hand_merge(text),
    )


def context_error(text: str) -> str | None:
    import torch

    from llm101.model import GPTConfig, TinyGPT

    ids = character_encode(text, add_bos=True, add_eos=True)
    config = GPTConfig(
        vocab_size=len(CHARACTER_VOCABULARY),
        d_model=16,
        n_layers=2,
        n_heads=2,
        d_ff=32,
        max_seq_len=CONTEXT_LIMIT,
    )
    model = TinyGPT(config, generator=torch.Generator().manual_seed(0))
    try:
        model.forward(torch.tensor([ids], dtype=torch.long))
    except ValueError as error:
        return str(error)
    return None
```

## 实际结果

在 `ch02/end` 里运行本节唯一的 stage：

```bash
cd ch02/end
uv run python scripts/show_tokenizer.py --stage 1
```

输出：

```text
stage 1 | character baseline + hand merge

text            the cat sat on the mat
chars           22
ids (24)        [66, 19, 7, 4, 52, 2, 0, 19, 52, 18, 0, 19, 52, 14, 13, 52, 19, 7, 4, 52, 12, 0, 19, 67]
unknown         0
decoded         'the cat sat on the mat'
hand merge      13 symbols; + specials = 15
symbols         ['the', ' ', 'c', 'at', ' ', 'sat', ' ', 'o', 'n', ' ', 'the', ' ', 'mat']
model           ValueError: sequence length 24 exceeds the model context of 16

text            小猫坐在垫子上
chars           7
ids (9)         [66, 65, 65, 65, 65, 65, 65, 65, 67]
unknown         7
decoded         ''
hand merge      7 symbols; + specials = 9
symbols         ['小', '猫', '坐', '在', '垫', '子', '上']
model           -
```

英文的第一个编号 66 是 `<bos>`，最后 67 是 `<eos>`；中间的 22 个编号对应 22 个字符。总数 24 超过 16，所以模型直接报错，连嵌入都还没有开始算。中文的 9 个编号里，66 和 67 是特殊 token，中间 7 个 65 全是 `<unk>`；`decoded` 是空字符串。

手写合并把英文的 22 个字符变成 13 个符号：`the`、空格、`c`、`at`、空格、`sat`、空格、`o`、`n`、空格、`the`、空格、`mat`。加上 `<bos>`/`<eos>` 是 15，终于进入上下文 16。`at` 被 `cat`、`sat`、`mat` 共用；`cat` 仍然保留为 `c` + `at`，`on` 仍然是 `o` + `n`。这说明手写合并只是把一小部分常见片段收拢起来，既不完整，也不根据语料统计；2.2 才会把“该合并谁”交给频率。

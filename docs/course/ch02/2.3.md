# 2.3 训练词表：语料、特殊 token 与目标大小

2.2 结束时，我们手里只有一份有序的合并列表：`('a','t')`、`('s','at')`……它能把字符序列变短，却还不知道每个片段对应哪个编号。这一节把合并列表变成词表：先收集语料里出现过的所有码点，再把三个特殊 token 放在最前面，最后按合并顺序追加新片段。目标设为 512 个 token：它比第 1 章的 68 个 token 大得多，能覆盖常见片段，又小到可以在 CPU 上快速训练和检查；8192 的词表留到第 7 章。

这一节还建立第 2–6 章共用的英中教学语料。语料是词表的来源；没有语料，就没有初始码点，也没有可统计的相邻对。

## 词表的组成

词表按固定顺序分三层：

1. **特殊 token**：`<unk>`（unknown，未知词元，词表外字符的替身）、`<bos>`（beginning of sequence，序列开头）和 `<eos>`（end of sequence，序列结尾）。它们不由合并产生，必须排在最前面。本章使用 `SPECIAL_TOKENS`（即 `("<unk>", "<bos>", "<eos>")`）的顺序，所以 id 分别是 0、1、2；构造函数允许调用者给出别的顺序，id 始终由 token 在词表里的位置决定。第 1 章的 `bos_id`/`eos_id` 是 66/67，这里变成 1/2；这是 tokenizer 自己的编号变化，`encode`、`decode`、`vocab_size`、`bos_id`、`eos_id` 五个接口的含义不变。本章不加 `<pad>`：还没有补齐序列的需求，等真正实现 padding 时再加。
2. **初始码点**（initial alphabet，初始码点表）：语料里出现过的所有不同 Unicode 码点，按字典序排列。英文的字母、空格、标点，中文的汉字，都在这一层。
3. **合并结果**：按 merge rank（合并在有序列表中的位置）依次追加的片段，例如 `at`、`low`、`小猫`。

用 $V$ 表示词表大小，$S$ 表示特殊 token 数，$A$ 表示初始码点数，$M$ 表示合并新增的 token 数：

$$
V = S + A + M
$$

本语料的具体数字是：

$$
V = 3 + 143 + 366 = 512
$$

如果两次合并得到同一个字符串，第二次不会让词表变大，所以 $M$ 可能小于合并次数；本节语料的 366 条合并各产生一个新 token，恰好等于合并次数。

## 本节需要实现的函数

本节实现 `BPETokenizer` 的构造、训练和只读属性。这里的“训练”只是统计合并：没有参数、没有损失，也没有反向传播；模型训练在第 6 章。`encode`、`decode`、`save`、`load` 仍然留给 2.4；所以本节结束时 `BPETokenizer` 还不是完整的 tokenizer，但已经能训练出词表并检查编号。

### `BPETokenizer.__init__`

构造函数的用途是把“原料”变成一个可检查的词表：特殊 token、初始 token、合并列表。它不读语料，也不训练；训练由 `train` 完成。特殊 token 按 `special_tokens` 给定的顺序编号。

输入是 `initial_tokens`（初始 token 序列）、`merges`（有序合并对）和可选的特殊 token 序列；输出是 tokenizer 对象。

它必须检查：特殊 token 不重复、不为空且包含 `<unk>`/`<bos>`/`<eos>`；初始 token 不重复、不为空、不与特殊 token 重名；每个合并对引用已经存在的 token；合并结果不能与特殊 token 同名；合并结果按字符串去重。这些检查放在构造时，是为了让坏词表在建立阶段就报错，而不是等到 2.4 的 `encode` 才暴露；那时错误离原因更远。

```python
def __init__(
    self,
    initial_tokens: Sequence[str],
    merges: Sequence[Pair],
    *,
    special_tokens: Sequence[str] = SPECIAL_TOKENS,
) -> None:
    # 校验原料；按特殊 token → 初始 token → 合并结果建词表
    ...
```

例如 `BPETokenizer(("a", "b", "c"), (("a", "b"), ("b", "c")))` 的词表是 `('<unk>', '<bos>', '<eos>', 'a', 'b', 'c', 'ab', 'bc')`，`unk_id`、`bos_id`、`eos_id` 分别是 0、1、2。

### `BPETokenizer.train`

`train` 是词表训练（vocabulary training，用语料统计合并并按顺序排定 token 与 id）的入口：收集初始码点、校验目标大小、计算需要合并多少次，再调用 2.2 的 `learn_merges`。

输入是若干条文本（`Iterable[str]`）、目标 `vocab_size`、可选的特殊 token 和最低频率 `min_frequency`；输出是构造好的 `BPETokenizer`。`min_frequency` 是相邻对进入合并列表的最低频率，默认 2 表示只合并至少出现两次的相邻对。

步骤是：

1. 把 `texts` 转成 `list[str]`，避免生成器只能读一次；
2. 收集所有非空文本的码点，按字典序排序，得到初始码点表（代码里叫 `alphabet`）；
3. 校验 `vocab_size >= len(special_tokens) + len(alphabet)`，否则报错并给出最小词表大小；
4. 计算 `num_merges = vocab_size - len(special_tokens) - len(alphabet)`；
5. 调用 `learn_merges(texts, num_merges, min_frequency=...)`；
6. 用 `initial_tokens`、`merges`、`special_tokens` 构造对象。

`vocab_size` 是目标上限：如果最高频相邻对的频率低于 `min_frequency`，`learn_merges` 会提前停止，实际词表可能小于目标。本语料恰好达到 512。

目标太小时必须报错，并给出最小词表大小。例如 `low`/`lower`/`lowest` 只有 7 个码点，特殊 token 3 个，最小词表是 10；目标 9 会报 `at least 10`。`vocab_size` 或 `min_frequency` 小于 1 也要报错。

```python
@classmethod
def train(
    cls,
    texts: Iterable[str],
    vocab_size: int,
    *,
    special_tokens: Sequence[str] = SPECIAL_TOKENS,
    min_frequency: int = 2,
) -> BPETokenizer:
    # 收集初始码点表；num_merges = vocab_size - len(special_tokens) - len(alphabet)
    ...
```

### 只读属性

`vocabulary` 按 id 返回 token 元组；`vocab_size` 返回长度；`unk_id`、`bos_id`、`eos_id` 返回三个特殊 token 的编号。它们只读，不重新训练。

用 `low`/`lower`/`lowest`、目标 12，词表是：

```text
("<unk>", "<bos>", "<eos>", "e", "l", "o", "r", "s", "t", "w", "lo", "low")
```

前三个是特殊 token；中间 7 个是按字典序排列的码点；最后两个是 rank 0–1 的合并结果。`unk_id`、`bos_id`、`eos_id` 分别是 0、1、2；按位置编号，`e` 是 3、`w` 是 9、`lo` 是 10、`low` 是 11。

## 参考实现

下面是 `BPETokenizer` 本节实现的参考代码。代码块是同一个模块的节选：文件顶部已经导入 `Iterable` 和 `Sequence`，`Pair`、`SPECIAL_TOKENS`、三个特殊 token 常量与 2.2 的 `learn_merges` 也定义在这个模块里。`encode`、`decode`、`save`、`load` 仍然是 `TODO 2.4`；训练和词表部分已经完整。

```python
from __future__ import annotations

from collections.abc import Iterable, Sequence

class BPETokenizer:
    def __init__(
        self,
        initial_tokens: Sequence[str],
        merges: Sequence[Pair],
        *,
        special_tokens: Sequence[str] = SPECIAL_TOKENS,
    ) -> None:
        special_tokens = tuple(special_tokens)
        initial_tokens = tuple(initial_tokens)
        merges = tuple((left, right) for left, right in merges)

        if len(set(special_tokens)) != len(special_tokens):
            raise ValueError("special_tokens must be unique")
        if any(not token for token in special_tokens):
            raise ValueError("special tokens cannot be empty")
        required = {UNKNOWN_TOKEN, BOS_TOKEN, EOS_TOKEN}
        if not required.issubset(special_tokens):
            raise ValueError(f"special_tokens must include {sorted(required)}")
        if len(set(initial_tokens)) != len(initial_tokens):
            raise ValueError("initial_tokens must be unique")
        if any(not token for token in initial_tokens):
            raise ValueError("initial tokens cannot be empty")
        if set(initial_tokens) & set(special_tokens):
            raise ValueError("initial tokens cannot collide with special tokens")

        vocabulary = list(special_tokens) + list(initial_tokens)
        known_tokens = set(vocabulary)
        special_set = set(special_tokens)
        for left, right in merges:
            if not left or not right:
                raise ValueError("merge pairs cannot contain empty tokens")
            if left not in known_tokens or right not in known_tokens:
                raise ValueError(
                    f"merge references an unknown token: {(left, right)!r}"
                )
            merged = left + right
            if merged in special_set:
                raise ValueError("a BPE merge cannot create a special token")
            known_tokens.add(merged)
            if merged not in vocabulary:
                vocabulary.append(merged)

        self.special_tokens = special_tokens
        self.initial_tokens = initial_tokens
        self.merges = merges
        self._vocabulary = tuple(vocabulary)
        self._token_to_id = {
            token: index for index, token in enumerate(vocabulary)
        }

    @classmethod
    def train(
        cls,
        texts: Iterable[str],
        vocab_size: int,
        *,
        special_tokens: Sequence[str] = SPECIAL_TOKENS,
        min_frequency: int = 2,
    ) -> BPETokenizer:
        if vocab_size < 1:
            raise ValueError("vocab_size must be positive")
        if min_frequency < 1:
            raise ValueError("min_frequency must be positive")

        materialized = list(texts)
        if not materialized or not any(materialized):
            raise ValueError("cannot train without non-empty texts")
        alphabet = sorted(set("".join(materialized)))
        special_tokens = tuple(special_tokens)
        minimum_size = len(special_tokens) + len(alphabet)
        if vocab_size < minimum_size:
            raise ValueError(
                f"vocab_size={vocab_size} is too small for the observed alphabet; "
                f"need at least {minimum_size}"
            )

        merges = learn_merges(
            materialized,
            vocab_size - minimum_size,
            min_frequency=min_frequency,
        )
        return cls(
            initial_tokens=tuple(alphabet),
            merges=merges,
            special_tokens=special_tokens,
        )

    @property
    def vocabulary(self) -> tuple[str, ...]:
        return self._vocabulary

    @property
    def vocab_size(self) -> int:
        return len(self._vocabulary)

    @property
    def unk_id(self) -> int:
        return self._token_to_id[UNKNOWN_TOKEN]

    @property
    def bos_id(self) -> int:
        return self._token_to_id[BOS_TOKEN]

    @property
    def eos_id(self) -> int:
        return self._token_to_id[EOS_TOKEN]
```

## 与 2.4 的交接

词表现在是“特殊 token → 初始码点 → 合并结果”的固定序列。2.4 要在这个序列上实现：

- `encode`：从码点开始，按 rank 重放合并，再查 id；未知字符的处理在 2.4 展开；
- `decode`：逐 id 查回片段并拼接，默认跳过三个特殊 token；
- `save`/`load`：保存特殊 token、初始 token、合并列表和格式版本，加载时重建词表。

`BPETokenizer` 的 `encode`/`decode`/`save`/`load` 现在仍是 `TODO 2.4`；本节只保证词表本身正确。`test_tokenizer_contract_round_trip` 和 `test_vocab_size_matches_model` 仍然失败，就是因为它们要用 `encode`。

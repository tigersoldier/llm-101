# 数据与许可

## 当前主训练语料方案

基础模型使用短故事语料，分别准备英文、中文和中英混合版本。原始数据不会提交到仓库；代码将提供下载、校验和预处理步骤。训练管道不预先下采样，限时实验到点停止，并记录训练实际读取的 token 数与各语言覆盖情况。

- 英文候选：[roneneldan/TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories)，标准版。数据卡说明故事由 GPT-3.5/GPT-4 生成，许可证标为 CDLA-Sharing-1.0。
- 中文候选：[52AI/TinyStoriesZh](https://huggingface.co/datasets/52AI/TinyStoriesZh)。其说明称文本是从英文 TinyStories 翻译而来；数据卡标 MIT，但上游 TinyStories 标为 CDLA-Sharing-1.0。项目将保留完整来源链和许可证说明，不把中文镜像的标签当作上游授权的替代。
- 双语版：将两种语言的完整训练语料混合，不添加语言控制 token；使用联合训练的 BPE 词表。实验会记录实际中英文 token 数，而不是只报告总量。

## 切分与使用

英文优先采用数据源提供的训练/验证划分；中文按故事划分验证集，避免同一故事同时出现在训练和验证数据。双语版在各自切分后再混合。数据文件、缓存和预处理产物保存在本地 `data/`，不进入 Git。

具体数据版本、下载方式、校验值、样本数量及每个文件的署名和许可，应在数据管道实现时再次核验，并记录在模型发布说明中。模型权重发布前也要单独复核上游许可及生成样例；本页不是法律意见。

## 小型对照语料

[Global ASP 中文故事目录](https://github.com/global-asp/global-asp/tree/master/zh)包含少量中文故事，且不同故事许可不同；它可用于检查格式或做补充对照，不能在未筛选许可时整体使用。数据卡标注为公开，也不意味着可以忽略具体许可和署名要求。

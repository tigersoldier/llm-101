# 图表规范

这张清单把全书图的通用要求和第 1 章积累的具体做法放在一起。新增或修改图后，按本页逐条检查；不通过不算完成。评审流程和工具见 `llm101-figure-review` skill，本页是书稿侧的完整规则。

## 1. 什么时候画

- 结构、数据流、矩阵或多阶段变化能说明问题的概念与计算，各配一张 SVG。
- 只承载一条公式、删掉也不损失信息的图不画，公式直接排版。
- 回顾性的小节不重复画新图，引用前一节的图即可；回顾旧组件时必须在图里画出它的形状。
- 有新概念的扩展阅读至少配一张图；扩展阅读的图可以是结构图、原始用法示意或对比曲线。

## 2. 分带、方向与中心线

- 每个阶段独占一条横向带；带与带之间的主箭头一律竖向。
- 横向箭头只出现在同一条带内：并列项、成对运算、逐位置重复。
- 中间特征向量必须竖向；只有最终输出向量可以横向。
- 主链路只有一条中心线，所有阶段沿它对齐。
- 一个矩阵拆成两路时，父矩阵居中于两路之间；两路合回一个结果时，两个父矩阵关于子矩阵对称。
- 只画本节已有的步骤；后续组件不出现。真组件用实线彩色；本节已有但尚未实现的组件可以用虚线灰色并标“占位”。

## 3. 矩阵与标签

- 矩阵的行和列连续、无间隙；每个显示的格子有值；省略用 `⋮`、`⋯`，行列数要对得上形状。
- 矩阵在带框块内水平居中，不贴边；最终结果不加多余的外框。
- 轴角色只在**第一次出现**和**角色/朝向变化**时标：
  - 第一次：`位置（T 行）↓`、`特征（C 列）→`；
  - 角色不变：后续矩阵沿用，不重复标；
  - 角色变化：例如特征列变成词表列、发生转置，必须重新标。
- 带框块只量两个间距：`title_top_gap`（框顶到标题文字顶）和 `matrix_bottom_gap`（矩阵底到框底），二者必须相等。不要拿“矩阵到框顶”去比“矩阵到框底”，矩阵上方还包含标题带。
- 框内标题居中。无框矩阵的标签可以左对齐或偏移以避开箭头；只要求离箭头轴线至少 8px，并且有自己的垂直带，不要挤在入边箭头的间隙里。
- 每个标签、箭头、边框、矩阵都不能互相重叠；无框标签不能被箭头穿过。

## 4. 箭头

- 箭头尾从有名元素的边缘出发；箭头尖接到目标边框，或停在目标上方 1–2px。
- 不悬空、不穿过标签或矩阵、同一转换只有一条箭头。
- 两条路径共同决定一个结果时，汇到结果输入边上的同一点，用一个汇合点标出。
- 竖向箭头等长；层间节奏一致，不因某个标签而忽长忽短。

## 5. 文字、公式与图注

- 公式按 MathJax 排版：斜体变量、真实上下标、`×`、`Σ`、`\sqrt{d_k}`；不要写 `sqrt`、`^T`、`*`。
- 中文用真实浏览器截图检查，不能用 `rsvg-convert` 的缺字结果代替。
- 每张图有编号图注，例如 `图 1.6-2：…`；写清解释的是哪一步、样例取值（如 `C=4、H=2、T=3`）和数值是否来自随机权重。
- 单张图用 Markdown 图片加下一行 `*图 1.x-n：…*`；需要并排或点击放大的图用 `<figure>` + `<figcaption>图 1.x-n：…</figcaption>`。
- 图注要说明颜色和实线/虚线的含义。

## 6. 对比图与删图

- A/B、前后对比画成两张独立 SVG，放进 `.figure-pair`：宽屏并排，≤700px 上下堆叠；不要把两个面板烤进一张宽图。
- 只承载一条公式、不承载结构或数据流的图删除；公式直接排版。
- 回顾旧概念时至少画一个缩略结构图，不能只写组件名字。

## 7. 放大、缓存与响应式

- 图可点击放大；放大必须使用同一份 SVG 的矢量放大，不能把 SVG 截成位图。
- 打开浮层时用 `history.pushState` 记录；Back 关闭浮层而不离开页面；×、Esc、点击背景也能关闭。
- 改动某个 SVG 后，把它所有引用处的 `?v=N` 加一；没改的图不加。
- 手机宽度下只检查裁切、溢出和意外重叠，不把字号大小当作失败门槛；密集矩阵可以依赖点击放大阅读。

## 8. 审核

- 每张新增或修改的图在 1400px、700px、390px 三个宽度下用真实浏览器检查。
- 检查项：中心线、分带、箭头、矩阵、轴标签、边距、标签净空、文字重叠、裁切、中文渲染、图注、`?v=N`。
- 修改图后必须由独立 reviewer 按本页和 `llm101-figure-review` checklist 返回 PASS；FAIL 时先修图，不要先报告完成。
- 生成器加 `--output` 参数，不要用 shell 重定向覆盖 SVG；生成器和 SVG 必须同步。

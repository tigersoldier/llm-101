# 1.4 位置嵌入

- 状态：完成
- 预计篇幅：约 2600 字，代码 3 处，图 2 张
- 前置：1.3

## 目标

- 理解只有词嵌入时，同一批 token 打乱顺序后向量集合不变，顺序信息丢失
- 理解位置嵌入是可学习的第二个查表，形状 `[max_seq_len, d_model]`
- 掌握 `h_t = E[id_t] + P[t]` 的逐元素加法和 `[T, C]` 形状
- 理解 `max_seq_len = 16` 与上下文越界检查
- 知道位置表有 `16 × 16 = 256` 个数字

## 内容安排

1. 问题：词嵌入只按 token 取行，同一 token 在任何位置都得到同一向量
2. 思路：位置表 `P`，每个位置一行；加到词向量上
3. 定义：位置嵌入、位置编号 0..T-1、`max_seq_len=16`
4. 最小例子：同一个 token 19 在位置 0/1 的 `E[19]`、`P[0]`/`P[1]`、`h_0`/`h_1`
5. `TinyGPT.__init__` / `forward`：两张表、越界检查、位置相加
6. 占位管线 stage 4 的实际输出、`06-pipeline.svg` 与 `architecture-4.svg`
7. 验收：`test_context_limit`、位置不同断言、stage 4

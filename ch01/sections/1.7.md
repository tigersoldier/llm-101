## 目标

- 理解 Pre-LN block 的两条残差路径

## 内容安排

1. 问题：一层注意力缺少逐位置的非线性，深层缺少残差
2. block 的计算顺序：`x + attn(ln(x))`，再 `x1 + mlp(ln(x1))`；`15-block.svg`
3. Pre-LN 与 Post-LN 的对比、`10-pre-ln.svg`/`10-post-ln.svg`、Xiong 等人 2020 年的分析
4. MLP：先扩大、GELU、再压回；为什么不能只用一个 Linear、两个 Linear 或一个直接作用在输入上的 GELU；`d_ff=2C` 与标准 `4C` 的取舍；`17-mlp.svg`
5. 回顾 LayerNorm、GELU、多头自注意力的公式和形状
6. `TransformerBlock` 与 `MLP` 的用法、输入输出、cache 和参考实现
7. 一个 block 2,224 个参数；两层 block 4,448；`18-block-pipeline.svg`
8. 与上游 1.6 架构图的关系；`architecture-6.svg`；1.8 接整模型
9. 扩展阅读：感知机、XOR、隐藏层、万能近似、残差与 Pre-LN

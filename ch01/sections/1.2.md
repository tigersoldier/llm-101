# 1.2 字符级 tokenizer 与接口

- 状态：完成
- 预计篇幅：约 600 字，代码 1 处
- 前置：1.1

## 目标

- 能把文本变成 id 序列再还原，理解 `vocab_size`、`bos_id`、`eos_id`
- 理解为什么第 1 章用字符级，第 2 章会在同一接口后面换成 BPE
- 知道未知字符怎么处理，以及为什么这里不做子词切分

## 内容安排

1. 字符级切分的取舍：词表小、任意英文可输入、序列变长
2. 特殊 token 的作用：序列边界与填充占位的区别
3. `encode` / `decode` 的实现要点与往返一致性
4. 未知字符策略（报错还是映射到 `<unk>`）与选择理由
5. 与第 2 章的接口契约：`encode`、`decode`、`vocab_size`、`bos_id`、`eos_id` 五个成员不变

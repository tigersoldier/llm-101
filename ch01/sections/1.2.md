# 1.2 字符级 tokenizer 与接口

- 状态：完成
- 预计篇幅：约 1100 字，代码 2 处，图 1 张
- 前置：1.1

## 目标

- 能把文本变成 id 序列再还原，理解 `vocab_size`、`bos_id`、`eos_id`
- 理解为什么第 1 章用字符级，第 2 章会在同一接口后面换成 BPE
- 知道未知字符怎么处理，以及为什么这里不做子词切分

## 内容安排

1. 字符级切分的取舍：词表小、任意英文可输入、序列变长
2. 特殊 token 的作用：序列边界与填充占位的区别
3. 本节需要实现的函数：逐个函数写用法、输入输出、样例与签名
4. 参考实现：`encode` 与 `decode`
5. 每个函数的结果：编号、往返、特殊符号、词表大小
6. 本节结束后的管线：`--stage 2` 输出与架构图
7. 与第 2 章的接口契约：五个成员不变

## 写作注意

- 第 2 章的 BPE 必须实现同一组方法，本章定下的签名不要在第 2 章改。
- 术语译名：`tokenizer` 首次出现写全“分词器、标记器、词元切分器”；`token` 译作“词元”（也译作“标记”）。
- 特殊符号写出全称：`<bos>` = beginning of sequence，`<eos>` = end of sequence，`<unk>` = unknown，`<pad>` = padding。
- 示例固定 `the cat sat`，与 1.1 一致；末尾贴 `--stage 2` 的实际输出和本节架构图。
- 按“本节需要实现的函数 → 参考实现 → 每个函数的结果”组织，结果写清输入输出。
